# Glossary

Key terms used throughout the StudentCenter project.

| Term | Definition |
|------|-----------|
| **Admin** | Vice Principal of Student Affairs; highest access role. See [[User Roles]]. |
| **Announcement** | School-wide notice posted to the [[Feature - Digital Bulletin Board]]. See [[Entity - Announcement]]. |
| **App Router** | Next.js routing system using `app/` directory structure. See [[Frontend Overview]]. |
| **Clean Architecture** | Architectural pattern separating Domain, Application, Infrastructure, and Presentation layers. See [[Clean Architecture]]. |
| **DTO** | Data Transfer Object; request/response shapes in the Application layer. |
| **EF Core** | Entity Framework Core; .NET ORM used for database access. |
| **Fluent API** | EF Core method for configuring entity-to-table mappings in code. |
| **JWT** | JSON Web Token; used for [[Authentication]] bearer tokens. |
| **Mading** | Indonesian for "bulletin board" (Majalah Dinding). See [[Feature - Digital Bulletin Board]]. |
| **NIP** | Nomor Induk Pegawai; Teacher/Admin employee ID for login. |
| **NIS/NISN** | Nomor Induk Siswa; Student ID for login. |
| **OSIS** | Organisasi Siswa Intra Sekolah; student council. See [[User Roles]]. |
| **PagedResult** | Generic wrapper for paginated API responses. |
| **Scoped** | DI lifetime; one instance per HTTP request. |
| **Seeder** | Startup code that populates initial database data. See [[Authentication]]. |
| **Server Component** | React component rendered on the server (default in Next.js App Router). |
| **Client Component** | React component requiring `"use client"` directive for interactivity. |
| **shadcn/ui** | UI component library planned for the frontend. |
| **Supabase** | Backend-as-a-Service providing managed PostgreSQL. See [[Database Schema]]. |
| **Waka Kesiswaan** | Vice Principal of Student Affairs (Admin role). |
