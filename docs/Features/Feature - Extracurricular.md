# Feature - Extracurricular

Club and extracurricular activity management.

## Status

**Not started** (planned per [[API Contract]])

## Planned Features

- Club list and detail pages
- Student registration for clubs
- Member list management
- Attendance tracking
- Teacher as advisor (relationship-based, no separate role)

## Planned Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/v1/clubs` | List clubs |
| POST | `/api/v1/clubs` | Create club |
